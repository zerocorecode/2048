# Audio Asset Notes

This application uses the same WAV assets as the adjacent `Threes` project:
one slide clip, 48 merge feedback clips, 32 invalid-move feedback clips,
`click.wav` for ordinary buttons, and `deepClick.wav` for the AI auto button.
The files were copied without modification. Their original local source
directories are documented in `../Threes/THIRD_PARTY_NOTICES.md`.

The source directories do not contain license metadata. Distribution rights
should be confirmed before publishing the APK.

## Tile Number Font

Tile numbers, scores and the next-tile preview use the same `Numbers-Premium.otf`
as Threes. The supplied font is copied without modification to
`app/src/main/res/font/numbers_premium.otf`.
Original local source: `D:\misc\资源\游戏资源整理\字体\Numbers-Premium.otf`.
The source directory does not contain license metadata.
